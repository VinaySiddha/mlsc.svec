# Social Media Guidelines

MLSC SVEC maintains active public profiles on LinkedIn, Instagram, X (Twitter), and YouTube.

---

## 1. Platform-Specific Strategies

- **LinkedIn:** Professional event recaps, project launches, hackathon winner spotlights, speaker appreciation, and internship accomplishments.
- **Instagram:** Visual carousels, event countdown stories, behind-the-scenes reels, core team intros, and quick tip carousels.
- **X (Twitter):** Tech commentary, live event updates, open-source pull request highlights, and thread breakdowns of AI architectures.
- **YouTube:** High-definition workshop recordings, hackathon demos, and technical tutorial series.

---

## 2. Mandatory Hashtags & Mentions

Include where applicable:
- `#MLSC` `#MLSA` `#MicrosoftLearn` `#SVEC` `#StudentDevelopers` `#TechCommunity`
- Mention `@MicrosoftLearn` and official college handles when posting major milestones.
