# Resource Usage Policy

MLSC SVEC receives compute grants, lab allocations, and institutional hardware to support student learning. These resources must be managed responsibly.

---

## 1. Cloud & API Compute Quotas

- **Azure & GCP Credits:** Compute credits provided through Microsoft / Google student grants must only be used for approved club applications, hackathons, and research projects.
- **Crypto-Mining Strictly Prohibited:** Using club servers or cloud instances for cryptocurrency mining, distributed scanning, or unauthorized workloads will result in immediate disciplinary and legal referral.
- **Cost Monitoring:** Set up budget alerts on cloud subscriptions at 50%, 75%, and 90% thresholds.

---

## 2. Physical Lab & Hardware Assets

- Club microcontrollers, sensors, projectors, extension boards, and cameras must be checked out through the Event Lead.
- Return all equipment within 24 hours of event completion.
- Any damaged or malfunctioning hardware must be reported immediately.
