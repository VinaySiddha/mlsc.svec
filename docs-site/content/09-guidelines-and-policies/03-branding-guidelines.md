# Branding & Visual Identity Guidelines

To maintain strong brand recognition across campus and social platforms, adhere to the following visual standards.

---

```text
┌──────────────────────┬───────────┬─────────────────────────────────────┐
│ Color Name           │ Hex Code  │ Primary Usage                       │
├──────────────────────┼───────────┼─────────────────────────────────────┤
│ Microsoft Azure Blue │ #4285F4   │ Primary CTA buttons, badges, links  │
│ Terminal Green       │ #34A853   │ Success states, completed badges    │
│ Amber Gold           │ #FBBC05   │ Warnings, leaderboard trophy accents│

│ Surface Dark         │ #0A0A0A   │ Card background, navigation bars    │
└──────────────────────┴───────────┴─────────────────────────────────────┘
```

---

## 2. Typography

- **Headings & Display:** Google Sans / Inter Display with bold uppercase tracking (e.g. `tracking-wider`).
- **Body & Content:** Inter / Geist Sans for clean readability.
- **Code & Terminals:** JetBrains Mono / Fira Code.

---

## 3. Logo & Badge Usage Rules

- Do not alter the proportions, stretch, or rotate the official MLSC SVEC logo.
- Maintain adequate clear space around the logo equal to at least half the icon's width.
- Always overlay the logo on dark or transparent backgrounds for optimal contrast.
