# Admin Usage Guidelines

The MLSC SVEC Admin Suite (`/admin`) provides centralized controls for the entire club platform.

---

## 1. Navigating the Admin Suite

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        ADMIN PORTAL MODULES                            │
├──────────────────────────┬─────────────────────────────────────────────┤
│ Module                   │ Administrative Functionality                │
├──────────────────────────┼─────────────────────────────────────────────┤
│ /admin/events            │ Create, edit, publish, and delete events    │
│ /admin/events/new        │ Setup ticket tiers, dates, and venues       │
│ /admin/applications      │ Review volunteer & hiring applications      │
│ /admin/team              │ Manage domain leads, roles, and rosters     │
│ /admin/payments          │ Review payment receipts, approve tickets    │
│ /admin/payments/ledger   │ Track club revenues and event expenditures  │
│ /admin/gallery           │ Upload and curate event photography         │
│ /admin/home-config       │ Reorder carousels, hero slides, ambassadors │
│ /admin/bulk-mail         │ Dispatch transactional & announcement emails│
│ /admin/operations/bugs   │ Triage bug reports and user support tickets │
└──────────────────────────┴─────────────────────────────────────────────┘
```

## 2. Pre-Publish Verification Rule

Before publishing an event or sending bulk communication:
1. Verify event dates and times against the academic calendar to avoid exam conflicts.
2. Ensure ticket capacity matches physical room limits.
3. Test all registration and payment flows on a test account.
4. Send a test email to the administrative council before triggering a broadcast to all users.
