# Post-Event Process & Retrospective

Within 72 hours of an event's conclusion, the organizing team executes the standardized post-event closure workflow.

---

## 1. Post-Event Closure Checklist

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        POST-EVENT CLOSURE TASKS                        │
├────────────────────────┬───────────────────────────────────────────────┤
│ 1. Feedback Dispatch   │ Send anonymous feedback form to all attendees │
├────────────────────────┼───────────────────────────────────────────────┤
│ 2. Photo Gallery Upload│ Curate top 20 photos & upload to              │
│                        │ mlscsvec.com/admin/gallery                    │
├────────────────────────┼───────────────────────────────────────────────┤
│ 3. Financial Settlement│ Submit bills, receipts, and reconcile balance │
│                        │ in mlscsvec.com/admin/payments/ledger         │
├────────────────────────┼───────────────────────────────────────────────┤
│ 4. Thank You & Recaps  │ Publish LinkedIn/Instagram recap post and     │
│                        │ thank guest speakers / sponsors               │
├────────────────────────┼───────────────────────────────────────────────┤
│ 5. Team Retrospective  │ 20-minute internal team sync: What went well? │
│                        │ What could be improved? Log lessons in docs.  │
└────────────────────────┴───────────────────────────────────────────────┘
```

---

## 2. Event Archive Documentation

For every major event, a brief summary report is committed to the club records containing:
- Total Registered vs. Total Attended
- Net Financial Summary (Revenue vs Expenses)
- Top 3 Qualitative Feedback Takeaways
- Direct links to slide decks, recorded video feeds, and GitHub starter templates.
