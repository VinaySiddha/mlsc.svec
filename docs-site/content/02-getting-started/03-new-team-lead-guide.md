# New Team Lead Guide

As a **Domain Lead**, you are both a technical architect and a team mentor. Your role is to guide your domain's volunteers, maintain project momentum, and ensure deliverables meet MLSC SVEC quality benchmarks.

---

## 1. Key Lead Responsibilities

- **Domain Roadmap Ownership:** Define semester milestones, technical topics, workshop curricula, and software issues for your domain.
- **Task Delegation & Accountability:** Break down complex projects into actionable GitHub issues or Kanban tasks with clear deadlines and assignees.
- **Volunteer Mentorship:** Conduct weekly 1-on-1s or mini-syncs to unblock junior developers and designers.
- **Executive Reporting:** Present progress, metrics, and blocker reports at the weekly Sunday Council sync.

---

## 2. Standard Operating Procedures (SOPs) for Leads

1. **Sprint Planning:** At the start of every month, create GitHub milestone tickets representing the month's deliverables.
2. **Reviewing Pull Requests / Designs:** Review volunteer submissions within 48 hours. Provide constructive, actionable feedback focusing on architecture, edge cases, accessibility, and code readability.
3. **Cross-Domain Coordination:** When building a new feature (e.g. event registration flow), coordinate proactively with the Design Lead for UI components and the Marketing Lead for promotion copy.
4. **Enforcing Documentation:** Every feature built by your domain must have an associated markdown spec in `docs.mlscsvec.com` before it is marked complete.
