# Master Continuity Checklist

Before an outgoing leadership cohort departs, all items below must be signed off by both the Outgoing Lead Ambassador and Incoming Lead Ambassador, with final review by the Faculty Advisor.

---

## 1. Administrative & Governance Sign-Off

- [ ] Faculty Advisor briefed and introduced to incoming executive team.
- [ ] Financial balance reconciled; bank/UPI accounts transitioned.
- [ ] Active sponsorship records and corporate partner contacts transferred.
- [ ] Portal admin rights assigned to incoming team in `/admin/team`.
- [ ] Outgoing team permissions downgraded from `/admin`.

---

## 2. Technical & Cloud Infrastructure Sign-Off

- [ ] GitHub Organization Owner privileges transferred to incoming Tech Lead.
- [ ] Cloudflare DNS & SSL access verified by incoming DevOps team.
- [ ] Firebase / Google Cloud IAM Project Owner role transferred.
- [ ] SSH keys for WebRTC SFU Linux servers provisioned and verified.
- [ ] Domain renewal dates, registrar accounts, and billing payment methods updated.

---

## 3. Digital Accounts & Media Sign-Off

- [ ] Discord server ownership and `@Admin` role transferred.
- [ ] WhatsApp Community and Announcement channels admin rights granted.
- [ ] LinkedIn, Instagram, and YouTube logins updated with new 2FA numbers.
- [ ] Figma Organization workspace admin privileges updated.

---

## 4. Documentation Sign-Off

- [ ] All operational changes reflected on `docs.mlscsvec.com`.
- [ ] Zero uncommitted or undocumented production scripts remaining.
- [ ] `docs.mlscsvec.com` verified as the active Single Source of Truth.
