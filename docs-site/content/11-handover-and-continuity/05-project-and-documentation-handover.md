# Project & Documentation Handover

A handover is considered incomplete if software projects and infrastructure are not fully documented and audited.

---

## 1. Documentation Completeness Audit

Before departing, every outgoing maintainer must verify:
- [ ] Every repository has an updated `README.md` with current local setup instructions.
- [ ] Architecture diagrams and API routes are accurately documented on `docs.mlscsvec.com`.
- [ ] Environment variable descriptions are complete and up-to-date.
- [ ] Known issues and technical debt items are logged in GitHub issues.

---

## 2. Project Maintainer Assignment

1. Assign incoming primary maintainers in the GitHub `CODEOWNERS` file.
2. Transfer open issue triage responsibilities.
3. Schedule a 45-minute codebase walkthrough session recording video architecture overviews.
